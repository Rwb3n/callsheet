# Retro: CS-WORK-031

**Date:** 2026-02-23
**Scope:** CS-WORK-031 — Claim approval and rejection pipelines (16 AC, S3, CH-CS-005)

---

## 1 — Reflection

| Prompt | Notes |
|--------|-------|
| **What surprised you?** | The existing AC-46 test broke silently when the auto-approve path started calling `onClaimApproved`, which deletes the snapshot that the test was asserting on. The test created an unclaimed listing with a `websiteUrl` that matched the claimer's email domain, so it auto-approved instead of routing to manual review. Test fixture defaults can create invisible coupling to decision logic. |
| **What went well?** | Clean decomposition of approval vs rejection into standalone functions with injected deps. Both pipelines tested directly (not through the router) which makes tests fast and focused. Expanding `ClaimRouterDeps` from 4 to 7 fields was mechanical — every upstream test file only needed the same 4-line addition. Zero type errors on first compile after wiring. |
| **Could have gone better?** | WORK.md deliverable path said `src/domains/platform/enquiry-delivery.ts` but the actual S2 stub lives at `src/lib/onboarding/deliver-pending-enquiries.ts`. Replaced the stub in-place rather than creating at the WORK.md path — correct decision, but the decomposer skill continues to suggest paths that don't match where code actually lands. |
| **Keep doing** | Testing pipelines as standalone functions (not through the router). Testing the router only for event emission and status return. This separation makes 24 tests run in ~20s instead of the ~24s the 28 evaluate-claim tests take through the full tRPC stack. |
| **Stop doing** | N/A — no anti-patterns introduced. |
| **Start doing** | When a work item adds deps to a router's dep bag, grep for all test files that construct that dep bag and update them in the same pass — before running any tests. The type checker catches it, but discovering it via `tsc` after writing all code is slower than doing it proactively. |

| 7 | Proactive dep-bag update across test files | Feature request | When a router dep type changes, all test files constructing that dep bag should be updated in one pass, not discovered via `tsc`. |
