Drizzle ORM's `eq()` doesn't catch uuid-vs-text column comparisons. | **Could have gone better?** | The 3-agent delegation that wrote the handler code didn't catch the uuid-vs-text type mismatch. Agent prompts included the schema column types but agents still wrote SQL that compared uuid to text directly. The `churn_analysis_log.account_id` being uuid (while `listings.account_id` is text) is a schema design inconsistency that creates recurring bugs. |
| **Keep doing** | Precise failure descriptions in handoff notes — listing each failure with root cause analysis, not just "4 tests fail". |
| **Stop doing** | N/A |
