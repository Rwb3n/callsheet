## 1 — Reflection

| Prompt | Notes |
|--------|-------|
| **What surprised you?** | The shadcn CLI (`npx shadcn@latest add`) handled Tailwind v4 flawlessly — installed `radix-ui` (unified package, not individual `@radix-ui/*` packages), generated components with `data-slot` attributes and OKLCH-ready class names. But it did NOT touch `globals.css` at all despite having `components.json` pointing to it. The theme CSS had to be written entirely manually. |
| **What went well?** | Parallel execution of W4 + W9 — fully independent work items with no cross-dependencies. shadcn CLI created all 7 primitives in a single command. The `@import "tw-animate-css"` + `@custom-variant dark` pattern replaced the old `tailwindcss-animate` plugin cleanly. Zero type errors on first pass. 353 unit + 591 integration = 944 tests, 0 failures. |
| **Could have gone better?** | Initial web search for shadcn + Tailwind v4 compatibility returned noisy results from 2024-era issues. The official docs (`/docs/installation/manual`) had the canonical CSS structure but required a separate fetch. Could have gone directly to the manual installation page instead of the general Next.js page. Also: the `@import "shadcn/tailwind.css"` import mentioned in some docs doesn't exist — `shadcn` is a CLI-only package, not a library with CSS exports. |
| **Keep doing** | Using the shadcn CLI for component generation rather than hand-writing primitives. The generated components follow current best practices (Radix unified package, `data-slot`, `cva` variants, `cn()` helper) without any manual intervention. |
| **Stop doing** | Searching multiple web pages when the official manual installation doc is the single source of truth for CSS structure. |
| **Start doing** | For Tailwind v4 CSS-first theming, bookmark the `@theme inline` block structure. Every new colour token needs three things: (1) CSS variable in `:root`/`.dark`, (2) `--color-*` mapping in `@theme inline`, (3) usage in component classes via `bg-{name}` / `text-{name}-foreground`. Missing any one breaks the chain silently. |
